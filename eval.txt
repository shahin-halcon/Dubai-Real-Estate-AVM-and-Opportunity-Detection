DUBAI REAL ESTATE AVM — MODEL EVALUATION SUMMARY
==================================================

Evaluation objective
--------------------
Estimate Dubai residential property transaction value using property
characteristics and recent area/project comparable-sales features.

Target
------
log_price = log(TRANS_VALUE)

Primary evaluation metrics
--------------------------
MAE  = Mean Absolute Error
RMSE = Root Mean Squared Error
R²   = Coefficient of Determination
MdAPE = Median Absolute Percentage Error
Within ±10% = share of predictions within 10% of actual value
Within ±20% = share of predictions within 20% of actual value

Important:
"Within ±10%" and "Within ±20%" are accuracy-style measures for
continuous valuation. They are NOT classification accuracy.

================

|---|---:|---:|---:|---:|---:|---:|

Model: XGBoost Regressor

Interpretation
--------------
- The final XGBoost model explains approximately 88.96% of the variance
  in the held-out target values.
- Typical percentage error is better represented by the MdAPE of 6.24%.
- About 68.0% of predictions fall within ±10% of the actual value.
- About 86.5% fall within ±20% of the actual value.
- The XGBoost model materially outperformed the two Ridge baselines on
  MAE, RMSE, R², MdAPE, and the ±10% accuracy-style metric.

DATASET / VALIDATION CONTEXT
============================

Historical modelling dataframe: 79,123 transactions
Clean backtest universe: 74,252 transactions
Transactions with future 30-day comparable signal: 63,206
Transactions with >=3 future comparables: 50,457

The valuation model uses point-in-time historical comparable features.
Future 30-day information is used only for the separate opportunity
backtest and is not used as an input to the valuation model.

IMPORTANT LIMITATIONS
=====================

1. Continuous prediction accuracy is not uniform across all properties.
   Individual estimates can have substantially larger errors than the
   median error.

2. The final XGBoost performance above is an offline held-out evaluation.
   It should not be interpreted as a guarantee of future property values.

3. The Streamlit inference layer still requires further verification of
   exact training-time comparable-feature reconstruction before the app
   should be described as production-grade AVM infrastructure.

4. The opportunity signal is a separate downstream research layer and
   should not be confused with valuation accuracy.
